# Smart FAQ Chatbot

An AI-powered chatbot that answers
student questions about college syllabus.

## Technologies Used
- Python
- Ollama
- Llama 3.2
- Streamlit

## Features
- Ask syllabus-related questions.
- Get AI-generated answers.
- Simple chatbot interface.

## How to Run

Install libraries:

pip install -r requirements.txt

Download AI model:

ollama pull llama3.2

Run chatbot:

streamlit run app.py
